This section gets you from a fresh machine to a running SWAT+ simulation.

If you have never run the model before, follow the pages in order:

1. [Install](install.md). Get the SWAT+ executable on your machine.
2. [Quick start: Ames_sub1](quick-start-ames.md). Run the small reference dataset shipped with the source repository.
3. [Project folder anatomy](project-folder-anatomy.md). Understand what is in a SWAT+ project directory and what each group of files does.
4. [Your first watershed](first-watershed.md). Build a project for your own area using QSWAT+ and run it.

If you only want to read about the model first, skip ahead to [Model theory](../model-theory/index.md).
