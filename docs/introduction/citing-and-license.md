## License

SWAT+ is released under the GNU Lesser General Public License, version 2.1 (LGPL-2.1). The full text is in the [`LICENSE`](https://github.com/swat-model/swatplus/blob/main/LICENSE) file in the source repository.

## How to cite

Cite the software release using the DOI:

> Arnold, J.G., Čerkasova, N., White, M.J., Bailey, R., Thorp, K., Jeong, J., Zhang, X., Ugraskan, T., van Griensven, A., Rathjens, H., Raj, C., Cai, X., Geter, W.F., David, O., Carlson, J.R., Le, K.N. *Soil and Water Assessment Tool Plus (SWAT+)*. https://doi.org/10.5281/zenodo.14983534

The DOI `10.5281/zenodo.14983534` resolves to the current release; each tagged release also has its own DOI on Zenodo.

The machine-readable citation lives in [`CITATION.cff`](https://github.com/swat-model/swatplus/blob/main/CITATION.cff) in the source repository. GitHub renders a "Cite this repository" button from this file.
