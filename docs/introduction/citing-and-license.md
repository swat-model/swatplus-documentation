## License

SWAT+ is released under the GNU Lesser General Public License, version 2.1 (LGPL-2.1). The full text is in the [`LICENSE`](https://github.com/swat-model/swatplus/blob/62.0.1/LICENSE) file of the source repository.

## Citing the software

Cite the model release used in the study, with its version and DOI. The author list below is the one in the repository's citation file at 62.0.1:

> Arnold, J. G., Čerkasova, N., White, M. J., Bailey, R., Thorp, K., Jeong, J., Zhang, X., Ugraskan, T., van Griensven, A., Rathjens, H., Raj, C., Cai, X., Geter, W. F., David, O., Carlson, J. R., and Chawanda, C. J. Soil and Water Assessment Tool Plus (SWAT+), version 62.0.1. https://doi.org/10.5281/zenodo.14983533

Releases are archived on Zenodo:

| DOI | Points to |
|-----|-----------|
| [10.5281/zenodo.14983533](https://doi.org/10.5281/zenodo.14983533) | all versions; resolves to the newest archived release |
| [10.5281/zenodo.22919722](https://doi.org/10.5281/zenodo.22919722) | release 62.0.0 |
| [10.5281/zenodo.14983534](https://doi.org/10.5281/zenodo.14983534) | release 61.0.2 |

When a release has a version DOI, cite that DOI so the exact code can be found again.

GitHub shows a "Cite this repository" button on the [repository page](https://github.com/swat-model/swatplus), built from the same citation file, with APA and BibTeX forms.

## Citing the documentation

When a statement comes from this site, cite the page and the documentation version shown in the version selector at the top of the page, for example "SWAT+ Documentation, revision 62.0.1, Soft calibration, https://docs.swat.tamu.edu/62.0.1/calibration/soft-calibration/".

## Older versions

Revisions before the move to GitHub are in the [modular_swatplus](https://bitbucket.org/blacklandgrasslandmodels/modular_swatplus) repository on Bitbucket.
