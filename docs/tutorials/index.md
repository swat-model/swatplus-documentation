This section takes the small datasets that ship in `swatplus/refdata/` and walks them apart piece by piece. Each tutorial assumes you have installed SWAT+ and read the [Getting Started](../getting-started/index.md) pages.

## Pages

- [Ames_sub1 walkthrough](../tutorials/ames-sub1.md). A one-subbasin, twelve-HRU watershed near Ames, Iowa, simulated 1975 to 2020. Open every input group, run, and read the outputs.
- [Osu_1hru walkthrough](../tutorials/osu-1hru.md). A single-HRU paddy near Osu, Korea, simulated 2010 to 2023. Same structure as Ames at the smallest possible scale.
- [Carbon notebook](../tutorials/carbon-notebook.md). The Jupyter notebook in `swatplus/jupyter_notebooks/carbon.ipynb` that plots the soil-carbon outputs.
- [Cookbook recipes](../tutorials/cookbook.md). Short, copy-and-paste edits: add an HRU, switch the PET method, switch to Green-Ampt, change the simulation period, turn on the carbon model.
