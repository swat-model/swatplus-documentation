The SWAT+ project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

The full text lives in the source repository as [`CODE_OF_CONDUCT.md`](https://github.com/swat-model/swatplus/blob/main/CODE_OF_CONDUCT.md). To report a violation, contact the maintainers listed there.

Anyone contributing to SWAT+ (issues, pull requests, code review, mailing-list discussions) is expected to follow it.
